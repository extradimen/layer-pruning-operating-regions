# Manuscript availability text — draft until deposit

Code, selected masks, per-question derived outcome metrics, paired serving measurements, configuration and cost tables, statistical outputs, and figure-generation scripts are prepared as a curated reproducibility package. The package allows independent recomputation of the principal and historical statistical families and manuscript figures from released measurements. It does not include upstream model weights, benchmark text, generated answers, native checkpoints, or private operational receipts. The repository and persistent archive identifier will be inserted after the public deposit is complete. Rerunning model selection and inference from upstream inputs requires separately obtaining the pinned model and dataset revisions and recreating the documented runtime and hardware conditions.
