# Public reproducibility package — release candidate

This package is organized in the order of the manuscript. The frozen study compares whole-block deletion at `k=1,2,3,4` across two models, four selection methods, and seeds 11/23/37. The `k=0` Dense reference is shared within each model; it is not four methods times three independent seeds. The E1 samples were previously observed and are not an official test-set confirmation. The MIT `LICENSE` covers original project-authored code; upstream models, benchmarks, and underlying text are not relicensed by this package. Derived scientific data are provided for reproducibility subject to the source rights noted in `SOURCE_AND_LICENSE_REVIEW.md`.

| Paper stage | Directory | What is included |
| --- | --- | --- |
| Design and protocol | `01_design/` | Frozen Stage A and B protocol, design, source mapping |
| Layer selection | `02_selection/` | Executed-stage Python source snapshots, three historical tabu k=3 mask/solver records per model, 96 compressed logical endpoints with masks, and two shared Dense endpoints |
| Native artifacts | `03_artifacts/` | Construction and reload-check source; no model weights |
| Quality and serving | `04_evaluation/` | Scorers and serving code, 23,232 artifact-question metric rows (including Dense) and 6,400 timed/warmup serving-arm observations |
| Inference and cost | `05_statistics/` | Stage A/B scripts, 52/196 configuration rows, 18/96 contrasts, and 7,874/37,853 cost events |
| Figures | `06_figures/` | Frozen Stage A/B figure-building source and a package-relative adaptation of the manuscript figure script |
| Earlier boundary analyses | `07_boundary/` | Frozen Qwen/Mistral summaries, 8,096 historical physical-artifact question rows, 192 output-length diagnostic rows, and related analysis code; separate from the primary family |

The stage Python modules are byte-identical copies of the local source files; `SOURCE_MAP.csv` records their origin and SHA-256. The only modified code is `06_figures/paper/build_paper_figures.py`, whose input paths point to this package's frozen statistics JSON. The source is grouped by paper logic, not rewritten as a new executable model pipeline. Operational specs and receipts contain local paths and controller identifiers, so the public package uses frozen protocol documents and curated results in their place. To rerun model computation, an independent group must obtain the two upstream model revisions and benchmark datasets under their own terms, configure paths and runtime for their system, and preserve the stated selection, scorer, precision, serving, and statistical rules. The package does not claim a one-command end-to-end model rerun.

The per-question table intentionally gives correctness or C4 NLL and limited telemetry, without benchmark text, gold answers, prompts, model generations, or model weights. `topology_id` connects each compressed physical artifact's question rows and serving rows to `02_selection/results/logical_endpoints.csv`; several logical endpoints can share one physical artifact. Dense question rows use `topology_id=DENSE` and map to `02_selection/results/dense_shared_endpoints.csv`. Each candidate's paired serving record contains its own contemporary Dense arm. The configuration tables and statistics JSON are the frozen reported aggregates. The cost CSVs omit only `source_archive`, whose original value contains private deployment paths; all numeric cost fields are retained.

`build_release.py` rebuilds the candidate from frozen project-local evidence; it is for the private source project and is not a public-user command. `verify_release.py` checks file hashes, study dimensions, row counts, and obvious local path or credential leaks. `05_statistics/recompute_primary.py` recomputes the 18/96 accuracy contrasts and all 64 physical-artifact paired-serving summaries from released rows. `07_boundary/recompute_boundary.py` checks both historical nine-contrast families, the output-length diagnostic, and Mistral paired serving. Both exact-value comparisons passed against frozen outputs. The seven figure layouts can be regenerated into `06_figures/paper/rebuilt_figures/`, preserving the hashes of the shipped figures. See `QUICKSTART.md` for commands and `RELEASE_GATES.md` for publication checks.

The released-data checks were validated on Python 3.12.2 with the versions in `requirements-analysis.txt`. These two dependencies describe the **analysis and figures only**; the model-inference runtime is a separate, larger environment and is not represented by this small file.

The exact limits of statistical recomputation and end-to-end model reruns are stated in `REPRODUCIBILITY_SCOPE.md`. In particular, this candidate is **not** sufficient for an independent one-command rerun of all experiments.

No `k=5` result exists in this primary matrix. Historical `k=6/9` and branch-pruning results cited by the manuscript are supplied separately in `07_boundary`; they are not pooled into the paper's main 0–4 whole-layer mechanism comparison. Their released quality and length-diagnostic rows exclude prompts, labels, and generations. The full forensic receipts and native artifact archives remain in the private project evidence bundle.
